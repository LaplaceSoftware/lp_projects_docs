# 016 — Glossary

Terms used consistently throughout this guide and in the platform itself.

---

## People and Organisations

| Term                                  | Meaning                                                                     |
| ------------------------------------- | --------------------------------------------------------------------------- |
| **Customer**                    | A customer *company* that buys from SAMTIA — not an individual person   |
| **Customer User** / Portal User | A person at a customer company who uses the Customer Portal                 |
| **Company Administrator**       | A customer user who can also manage their own colleagues' accounts and tags |
| **Standard User**               | A customer user who can shop and order but not manage colleagues            |
| **Account Manager**             | The SAMTIA employee who owns a set of customer companies                    |
| **Pricing Manager**             | A SAMTIA role focused on price lists and price rules                        |
| **Read Only Manager**           | A SAMTIA role that can view but not change                                  |
| **Super Administrator**         | A SAMTIA role with full access including configuration                      |

---

## The Two Portals

| Term                                | Meaning                                                                                |
| ----------------------------------- | -------------------------------------------------------------------------------------- |
| **Customer Portal**           | The customer-facing website where companies browse and order                           |
| **Account Management Portal** | The internal website where SAMTIA staff serve customers                                |
| **ERP Back Office**           | SAMTIA's underlying business system, used by administrators. Not covered in this guide |

---

## Buying and Selling

| Term                                   | Meaning                                                                                                          |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Draft Request**                | A basket a customer is still building. Private, editable, not yet sent to SAMTIA                                 |
| **Label**                        | The name a customer gives a draft request or order                                                               |
| **RFQ** — Request for Quotation | A draft request formally submitted for pricing                                                                   |
| **Quotation**                    | SAMTIA's priced response to an RFQ                                                                               |
| **PO** — Purchase Order         | The customer's formal order document, uploaded as a PDF to accept a quotation                                    |
| **Order**                        | Confirmed business being fulfilled                                                                               |
| **Target Price**                 | The price a customer says they are hoping to pay. Guidance for the Account Manager, not a commitment             |
| **New Product Request**          | A customer's request for a product not in the catalogue                                                          |
| **Shared Request**               | A draft basket a customer has flagged for their Account Manager's attention, without formally requesting a price |

---

## Sales Order Stages

| Stage                      | Plain meaning                                       | Who acts next   |
| -------------------------- | --------------------------------------------------- | --------------- |
| **Draft Request**    | Still being built, not yet sent to SAMTIA           | Customer        |
| **RFQ Submitted**    | A price has been requested                          | Account Manager |
| **RFQ Revised**      | The customer changed their request                  | Account Manager |
| **Quotation Issued** | A price has been offered                            | Customer        |
| **PO Submitted**     | The customer accepted and sent their order document | Account Manager |
| **Processing**       | Confirmed and being fulfilled                       | Account Manager |
| **Delivered**        | Complete                                            | Nobody          |
| **Rejected**         | The request was refused                             | Nobody          |
| **Cancelled**        | The business was stopped                            | Nobody          |

---

## Status Signals

| Term                                | Meaning                                                                                                   |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Schedule Status**           | Timing signal from the requested delivery date:**Late**, **On Time** or **Upcoming**    |
| **Requested Delivery Date**   | When the customer needs the goods                                                                         |
| **Quotation Viewed Date**     | When the customer opened the quotation                                                                    |
| **Quotation Downloaded Date** | When the customer printed or downloaded the quotation                                                     |
| **Action Required**           | A flag raised when a customer shares a draft request or posts a message. Cleared with**Reply Done** |
| **Pending Resubmission**      | The customer changed a quoted order but has not resubmitted it                                            |
| **Return Reason**             | The Account Manager's explanation for sending an order back                                               |

---

## Catalogue

| Term                              | Meaning                                                                                   |
| --------------------------------- | ----------------------------------------------------------------------------------------- |
| **Product Category**        | A branch of the browsing menu customers navigate                                          |
| **Brand**                   | A manufacturer customers can browse by                                                    |
| **Product Variant**         | A specific sellable version of a product — a size, a colour, a configuration             |
| **Product Attribute**       | A characteristic a product varies by, such as Size                                        |
| **Product Attribute Value** | A specific option, such as Large                                                          |
| **Product Tag**             | A label customers can filter the catalogue by                                             |
| **Product Badge**           | A small marker on a product card, such as*New* or *Sale*                              |
| **Product Notice**          | An important notice shown on a product page                                               |
| **Featured Product**        | A product promoted onto the customer Home page                                            |
| **Requires Consultation**   | A product needing a conversation before it can be ordered. Customers see*Call Required* |
| **Published**               | Whether a product is visible to customers at all                                          |

---

## Pricing

| Term                       | Meaning                                                                      |
| -------------------------- | ---------------------------------------------------------------------------- |
| **Price List**       | A set of prices offered to a group of customers                              |
| **Price Rule**       | One entry on a price list, setting the price for a product or group          |
| **Applies To**       | What a price rule covers — a product, a product variant, or a broader group |
| **Minimum Quantity** | The minimum quantity before a price rule applies. Used for volume pricing    |
| **Validity Period**  | The dates between which a price rule applies                                 |
| **Customer Segment** | A commercial segment of customers, carrying a default price list             |

---

## People Management

| Term                                                     | Meaning                                                                        |
| -------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **Account Enabled** / *Account Manager Approved* | The SAMTIA-controlled switch on a customer user                                |
| **Portal Access Enabled** / *Status*             | The customer-controlled switch on their own user                               |
| **User Tag**                                       | A label a customer company uses to group its own people                        |
| **Invitation**                                     | The e-mail sent to a new customer user with their access details and a QR code |
| **National ID / Iqama**                            | An alternative to an e-mail address for signing in                             |

---

## Communication

| Term                              | Meaning                                                                                      |
| --------------------------------- | -------------------------------------------------------------------------------------------- |
| **Chat**                    | Live conversation between a customer company and its Account Manager                         |
| **Comment**                 | A message attached permanently to a specific order                                           |
| **Account Manager Note**    | A standing statement about an order, written by SAMTIA and shown prominently to the customer |
| **Attachment**              | A file attached to an order or a customer record                                             |
| **Notification**            | An in-portal alert about something that happened                                             |
| **Online / Away / Offline** | Whether a person is currently using the portal                                               |

---

## Screen Elements

| Term                       | Meaning                                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Request Selector** | The header control deciding which draft request receives products you add                                          |
| **Action Items**     | The list of things needing your attention, shown on both home screens                                              |
| **Column chooser**   | The control for showing and hiding table columns                                                                   |
| **Filters**          | The panel narrowing a list by date ranges                                                                          |
| **Banner**           | A promotional image on a customer's Home page, optionally aimed at one customer and scheduled to run between dates |
