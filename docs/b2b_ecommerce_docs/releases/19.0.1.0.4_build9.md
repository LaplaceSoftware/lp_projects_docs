## Changes

- Admins can now manage pricelists end-to-end from the API — create, update, and delete pricelists, and manage the price rules/items within each one, including support for product variants and date-based validity (PR 665, 667, 686).
- Fixed pricelist item and currency-listing endpoints, and pricelist responses are now cleaner and more consistent (e.g. the pricelist name is returned where it was missing, and stray rule data was trimmed from pricelist details) (PR 669, 671, 683).
- Added a dedicated access-management data module so the screens, roles, and permissions for the new Pricelist admin screens are registered properly instead of relying on demo/setup data (PR 679, 686).
- Updated the Postman collection with the new pricelist and pricelist-item endpoints (PR 673).
